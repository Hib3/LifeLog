# いっぽ — 動けない日の、最初の一歩

うつ・双極性障害・不安・ADHD などメンタルの波で「分かっているのに動けない」人のための行動支援 PWA。
気合いではなく行動科学の仕組みで、最初の一歩を助けます。

## 機能と根拠

| 機能 | 根拠 |
|---|---|
| エネルギーチェックイン | 双極性障害のセルフモニタリング。レベルに応じて提案が変化(高すぎる日はブレーキを提案) |
| 2分スターター | 行動活性化療法+「2分ルール」+作業興奮。5秒カウントダウンはメル・ロビンスの5秒ルール |
| ボックス呼吸 | 米海軍SEALsの戦術呼吸(4-4-4-4)。自律神経の沈静化 |
| If-Then作戦 | ゴルヴィツァーの実行意図研究(実行率2〜3倍) |
| できたログ&おかえり回数 | 連続記録(ストリーク)を意図的に廃止。中断からの復帰を称える設計で自己批判を防ぐ |
| こころノート(日記・ライフログ) | スリー・グッド・シングス(セリグマン)。睡眠・服薬記録は双極性障害の社会リズム療法の基本。写真は端末内IndexedDBに保存 |

## iPhone(PWA)で使える機能

- **アプリバッジ**(iOS 16.4+):今日のチェックインがまだだとアイコンに赤バッジ
- **Wake Lock**:呼吸・タイマー中は画面が消灯しない
- **Web Share**:今日の記録を共有シートから送れる
- **音声ガイド**:ボックス呼吸を日本語読み上げ(目を閉じたまま使える)
- **永続ストレージ申請 + IndexedDB**:写真付きライフログをデータ削除から保護
- **時刻基準タイマー**:バックグラウンドでも正確。復帰時に自動再同期。対応端末では完了通知
- ※ 時刻指定のプッシュ通知は静的ホスティングでは不可。ガイド内でiOSショートカットのオートメーション活用を案内

## GitHub Pages へのデプロイ

公開URL: https://hib3.github.io/LifeLog/

1. このフォルダの中身をリポジトリの `main` ブランチへプッシュ
2. リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定
3. Actions の `Deploy GitHub Pages` が完了したら公開URLを開く

すべて相対パスなのでサブディレクトリ配信でもそのまま動きます。ビルド不要。

## プライバシー

記録はすべて端末内の localStorage のみ。外部送信は一切ありません。

## 動作環境

モダンブラウザ(Chrome / Edge / Safari / Firefox)。オフライン対応(Service Worker)。
スマホのブラウザメニューから「ホーム画面に追加」でアプリとしてインストールできます。

> ⚠️ 本アプリは医療行為ではありません。つらさが続く場合は医療機関へ。
